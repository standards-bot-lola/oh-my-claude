How to load your data
1
Refresh your stats

In Claude Code, run /stats to update the usage file.

2
Copy the file somewhere accessible

The stats file lives at ~/.claude/stats-cache.json — this folder is hidden and won’t appear in your browser’s file picker. Copy it to a folder you can browse to:

macOS / Linux cp ~/.claude/stats-cache.json ~/Documents/
Windows copy %USERPROFILE%\.claude\stats-cache.json %USERPROFILE%\Documents\
3
Drop or browse

Drag the file onto this page, or click the drop zone / + Add Machine button to open the file picker. You can load stats from multiple computers.
